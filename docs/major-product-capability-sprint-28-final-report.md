# BANTABATO — Major Product Capability Sprint 28

## Account Lifecycle, Privacy Controls & Data Rights

Sprint 28 adds a protected, member-owned Account Center that keeps account controls separate from matrimonial profile settings. The Privacy Center explains what each visibility choice does, what others can see, and what changes immediately. It integrates the existing profile, discovery, photo, Family Circle, location, notification, language/device, safety, recommendation, and membership boundaries without making any one setting override the others.

The additive migration introduces member account-state, lifecycle-event, and data-rights request records. Members can pause discovery, reactivate only within existing eligibility rules, request a data review, request deletion review after a fresh sign-in, and cancel an open request. Pause removes discovery and recommendation projection. A deletion request removes discovery projection and revokes current connections and related Family Circle sharing through existing authorization flows, but it is not a deletion claim. There is no fabricated data file, session ledger, other-session revocation, recovery channel, provider activation, external delivery, or real lifecycle action.

Session controls truthfully show only the current secure session and current-session sign-out. The account view never exposes identity documents, storage keys, signed media URLs, message content, safety evidence, staff records, credentials, internal policy data, or another member’s private information. Strong confirmation, fresh-authentication guidance, stale-action protection, transaction locks, request idempotency recovery, offline boundaries, plain-language copy, and keyboard-native controls are included.

Focused policy and source contracts cover lifecycle transitions, safety precedence, fresh-auth deletion, request cancellation, ownership, stale/concurrent guards, discovery/connection withdrawal, privacy projection, data boundaries, recovery, premium neutrality, and accessible confirmations. TypeScript, **399 tests across 82 files**, production build, and production dependency audit passed. Desktop/mobile checks were read-only; the unauthenticated browser showed the intended sign-in gate for the new protected route. Launch remains **NOT READY** pending a reviewed deletion-retention policy, authorized data-export generation/delivery, real session inventory/revocation, reviewed recovery channels, and consented usability testing.
