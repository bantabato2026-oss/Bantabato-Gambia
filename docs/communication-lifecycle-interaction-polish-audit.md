## Security and provider boundaries retained

The server continues to require active mutual-match conversation access for send/upload, stores voice object keys privately, returns signed voice URLs only after conversation authorization, and permits deletion only to the original sender. Family members remain isolated from member accounts, private communication, documents, call consent, internal safety data, and relationship decisions. Payment/OTP providers remain unconfigured and are out of scope.
